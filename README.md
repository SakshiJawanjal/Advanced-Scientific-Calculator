# Advanced Scientific Calculator

A responsive and user-friendly Scientific Calculator built using HTML, CSS, and JavaScript. The application performs basic arithmetic operations as well as advanced mathematical functions, providing a modern and intuitive interface for everyday calculations.

## Features

* Addition, Subtraction, Multiplication, and Division
* Percentage Calculations
* Square (x²) Function
* Square Root (√) Function
* Positive/Negative Sign Toggle (±)
* Decimal Number Support
* Clear and Backspace Operations
* Dark/Light Theme Toggle
* Responsive Design for Desktop and Mobile Devices

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Learning Outcomes

* DOM Manipulation
* Event Handling in JavaScript
* Mathematical Expression Evaluation
* Responsive Web Design
* Theme Switching Implementation

## Future Enhancements

* Scientific Functions (sin, cos, tan, log)
* Calculation History
* Keyboard Support
* Memory Functions (M+, M-, MR, MC)
